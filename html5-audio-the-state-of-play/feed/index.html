Firefox, Chrome and Opera have supported Opus for some time now. Please update the article to reflect these changes!

Opus is a terrific audio codec, having an overall size/quality ratio that surpasses AAC and Vorbis, while being open-source and royalty free. It also has a dynamically scalable bitrate that ranges from 6 to 510 Kb/s, from speech to HiFi music. You can read more here: http://opus-codec.org/

Right now, support in Internet Explorer for Opus and Vorbis is up for vote. Please support the free web (and better audio quality) by voting the suggestion up, even if you don’t use Internet Explorer. Since IE is currently the world’s #2 most popular Internet browser, its support will mean a lot to the web developer community. To vote all you need is an email address:
https://wpdev.uservoice.com/forums/257854-internet-explorer-platform/suggestions/6513488-ogg-vorbis-and-opus-audio-formats-support-firefox

Here are the results of a recent 96 Kb/s listening test between AAC, Opus, Vorbis, and MP3. Please note that MP3 was tested at 128 Kb/s so that it wouldn’t fail the test miserably:
http://listening-test.coresv.net/results.htm

Here are the results of a listening test at 64 Kb/s listening test. MP3 wasn’t tested as it would have ended up a mid-low anchor if it was tested. Also note that this test used an older and less optimized version of Opus (it still won):
http://listening-tests.hydrogenaud.io/igorc/results.html
