]]> By: Steve Faulkner http://html5doctor.com/the-main-element/#comment-2065907 Thu, 10 Dec 2015 11:41:03 +0000 http://html5doctor.com/?p=5081#comment-2065907

The problem now is, according to the spec I am only allowed to do it this way when the sidebar contents are unique to the page at hand – which in a WordPress scenario for example is hardly the case.

In practice there is nothing to stop you from doing so, there are no conformance constraints on child elements of main (it can contain any flow content. The definition is designed to discourage use of main as a catchall container.

So this is acceptable:

body
– header
– main
— aside
– footer
